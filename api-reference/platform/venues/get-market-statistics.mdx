title: "Get market statistics"
description: "Venue-reported statistics for each instrument, over the window its market declares. One result per requested instrument, in request order. An instrument without a value comes back as an Unavailable result with its error code, so one instrument cannot fail the batch. Served from Plurex's live feed for the market when one is running, otherwise fetched from the venue. No API key needed."
openapi: "/api-reference/platform/plurex-platform-api.yaml POST /api/v1/venues/query/GetMarketStatistics"

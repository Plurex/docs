description: "Closed candles for one market, price kind and interval, newest first. The forming candle is never included, and a page has no gaps. ByInstrument starts from the latest closed candle, ByInstrumentBefore from the candles that end at or before `before`; paging past the first page needs the market's listBefore. A price kind or interval the market does not list returns 422 NotSupported."

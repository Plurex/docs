The Platform API is a JSON-over-HTTP API with WebSocket streams for account activity. This reference is generated from the Plurex OpenAPI and AsyncAPI specifications. For concepts and how-to guides, start with [How Plurex works](/how-plurex-works).

## Base URLs

| Interface | Base URL |
| --- | --- |
| HTTP operations | `https://api.plurex.io` |
| WebSocket streams | `wss://api.plurex.io` |

## Specifications

The specifications are the contract. Use them to generate clients or validate payloads.

| Document | Covers |
| --- | --- |
| OpenAPI 3.2 (`plurex-platform-api.yaml`) | Every HTTP operation, schema and error |
| AsyncAPI 3.0 (`plurex-platform-async-api.yaml`) | The account order and transaction streams |

Download both documents from the API at `https://api.plurex.io/api/v1/spec/plurex-platform-api.yaml` and `https://api.plurex.io/api/v1/spec/plurex-platform-async-api.yaml`.

<Note>
  The specifications use OpenAPI 3.2 union nullability (`type: [string, 'null']`). If you generate a client, check that your generator decodes explicit `null` values. Also treat `ErrorCode` and other enums as open: new values can appear without a new API version.
</Note>

## Operations

Every HTTP operation is a `POST` with a JSON body to a path of this form:

```text
/api/v1/{domain}/{query|command}/{Action}
```

Queries read state and are always safe to repeat. Commands change state; each one documents whether it is safe to repeat. IDs go in the body, never in the path.

| Domain | Operations | Authentication |
| --- | --- | --- |
| [`venues`](/api-reference/platform/venues/list) | Public market data: venues, markets, order books, trades, prices, quotes, statistics, funding, open interest and candles | None |
| [`hosts`](/api-reference/platform/hosts/list) | Hosts and their markets (public), then trading on an account: orders, fills, balances, positions, margin, settings and transactions | Discovery: none. Account operations: API key |
| [`accounts`](/api-reference/platform/accounts/connect) | Connect, list and manage your accounts | API key |
| [`paper`](/api-reference/platform/paper/create) | Create and fund paper accounts, and choose their fee tier | API key |

Streams use the path `/api/v1/{domain}/stream/{Action}/{scope}`, for example `/api/v1/hosts/stream/SubscribeToAccountOrders/{accountId}`. They are listed beside their HTTP operations, under **Orders** and **Transactions**. See [Stream account updates](/guides/streams).

## Authentication

Send both headers on every authenticated request and on the stream upgrade request:

```http
X-API-KEY: <your API key>
X-API-SECRET: <your API secret>
```

Create keys and find your tenant ID on the **DevTools** page of the [Plurex app](https://platform.plurex.io). See [Authentication](/authentication).

## Badges

The specification tags operations with these badges, and operation descriptions refer to them:

| Badge | Meaning |
| --- | --- |
| No API key | Public. No authentication needed. |
| Check capabilities | Not every host or venue supports this operation. Check its [capabilities](/capabilities/overview) first, or expect `422 NotSupported`. |
| Paged | Returns pages. Follow `nextCursor` until it is `null`. |
| Batch | Takes a list of identifiers or instruments and returns one result for each. |
| Not safe to repeat | Repeating the call repeats its effect. If the outcome is unclear, check before retrying. |

description: "Cancels one open order. Ack means the host accepted the cancel; some hosts cancel asynchronously, so confirm the final state with the order stream or GetOrder. 404 OrderNotFound means the host does not know the identifier as an open order: it never existed, it closed and was forgotten, or it is not visible yet, so check rather than assume it is gone. 409 OrderAlreadyClosed means the order already finished and may have filled; do not retry. The clientOrderId variants cancel an order whose ID you do not have, such as after a SubmitOrder timeout."

description: "Ack means the host accepted the cancel. Some hosts cancel asynchronously, so the order may still be open briefly; confirm the final state with the order stream or GetOrder. 404 OrderNotFound means the host does not know the identifier as an open order: it never existed, it closed and the host has forgotten it, or it is not visible yet. Check with GetOrder or ListOpenOrders rather than assume it is gone. 409 OrderAlreadyClosed means the order already finished and may have filled; do not retry. Safe to repeat. ById works on every host. The clientOrderId variants, where the host supports them (cancelOrder capabilities), cancel an order whose ID you do not know yet, for example after a SubmitOrder timeout."

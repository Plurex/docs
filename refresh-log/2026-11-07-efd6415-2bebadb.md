## Topics

### API key access: new page, update

Keys are no longer the whole tenant. Each key has access set in the app: General (connect accounts, create paper
accounts), Paper accounts, Real accounts and Specific accounts, each with No access, Read only, Trade, Full or Custom.
Custom has account administration (read, rename, update connection, delete), execution (read, trade) and paper (deposit,
withdraw, set fee tier). Access only adds, real accounts are closed until granted, creating an account grants nothing
on it, and a new key starts with Trade on paper. No access to an account gives `404 AccountNotFound`; some access but not
this action gives `403 Forbidden`.

New page `platform/api-keys` owns it, with the operation each permission unlocks. `authentication` gained an Access
section and lost the "full access to all accounts" warning.

Pages: `authentication`, `quickstart` (the key now needs Create paper accounts and Full on paper),
`concepts/accounts`, `platform/add-exchange` (Connect accounts, then real access), `api-reference/platform/errors`.

Documented as the app shows it, never as the stored tree. `AGENTS.md` no longer bans per-key scopes, and now limits the
docs to what has appeared in the public API or the web app.

### Web app: new tab, new pages

The app's pages move to their own "Web app" tab, with screenshots: `platform/overview` (sign up, sign in, the layout),
`platform/terminal`, `platform/accounts`, `platform/add-exchange` (unchanged URL), `platform/api-keys` and
`platform/settings`. Existing URLs are unchanged. The 17 old redirects in `docs.json` are removed: the site is not in

Updated from the app: Sign in rather than log in, the new sign-up flow, User Settings in the top right menu, the profile

### Account security: update

Email changes need the password, password, email and 2FA changes send a notice and end other sessions, and a lost
authenticator is a support ticket. Documented in `platform/settings` as the app shows it. Attempt limits, session
durations and the back office recovery are left out: they are not in the app or the public API.

### Subscriptions removed: update

Subscriptions and plans are gone. The temporary per-tenant paper account limit that replaces them is not documented:
there is no monetisation plan yet. Authored mentions of a paper account limit were removed; `AccountLimit` stays in the
errors table as the spec defines it.

Pages: `concepts/accounts`, `quickstart`, `paper/overview`, `api-reference/platform/errors`.

## Topics

### Organisations, members and invites: new page

The tenant is now an organisation. Every user has Personal, which holds only them, and can create teams or be invited
to them. A switcher picks the organisation the app works in; the Organization page (Overview, Members, Invites) shows
while a team is selected. The owner can do everything and cannot leave or be removed; members read every account and
get more through the same access editor as an API key, saved with a second factor when 2FA is on. Invites go to an
email address, lapse after 7 days, are replaced by inviting again, and can be cancelled. Only the owner manages API keys.

New page `platform/organisations` owns it, in the Web app tab's "Access and security" group.

Pages: `platform/overview` (Personal, the switcher, the Organization page, a card), `platform/api-keys` (owner-only
keys), `platform/accounts` (selected organisation, New Account only when allowed), `platform/settings` (Organizations
tab, member access needs the code), `authentication`, `concepts/accounts`, `concepts/venues-and-hosts` (tenant is an
organisation).

`AGENTS.md` no longer bans organisations, teams or members; invite codes, other roles and the back office stay out.
